1. Funciones (Reutilización de Código)

UIModule.showToast() - app.js 
/**
 * Muestra una notificación visual en la pantalla.
 * @param {string} message - El texto a mostrar.
 * @param {string} type - Tipo de alerta ('success' por defecto, o 'error').
 */
const showToast = (message, type = 'success') => {
    // 1. Creamos un nuevo elemento 
 en memoria
    const toast = document.createElement('div');
    
    // 2. Usamos Template Literals (con backticks \`) para inyectar la variable "type"
    toast.className = \`toast \${type}\`;
    
    // 3. Insertamos HTML interno con el mensaje
    toast.innerHTML = \`
\${message}
\`;
    
    // 4. Agregamos el nuevo elemento al contenedor real en el DOM (la pantalla)
    toastContainer.appendChild(toast);
    
    // 5. setTimeout ejecuta código después de un tiempo (4000 milisegundos = 4 seg)
    setTimeout(() => {
        toast.remove(); // Eliminamos el elemento de la pantalla
    }, 4000);
};

Concepto Clave

Las funciones encapsulan lógica para no repetir código. Aquí usamos Arrow Functions, parámetros por defecto, y asincronía básica con setTimeout.

2. Manipulación de Arrays

AppController.applyFilters() - app.js 
/**
 * Filtra el array de mascotas según el texto ingresado en el buscador.
 */
const applyFilters = () => {
    // Obtenemos el arreglo completo de mascotas desde el estado
    const pets = StateModule.getPets();
    const searchTerm = inputBuscar.value.toLowerCase();

    // .filter() crea un NUEVO array iterando sobre cada mascota ('pet')
    // Si la condición retorna 'true', la mascota se incluye en el nuevo array
    const filteredPets = pets.filter(pet => {
        
        // .includes() verifica si un string contiene a otro string
        // Convertimos a minúsculas para que la búsqueda no sea sensible a mayúsculas
        const matchesSearch = pet.nombre.toLowerCase().includes(searchTerm) || 
                              pet.dueno.toLowerCase().includes(searchTerm);
        
        return matchesSearch; 
    });

    // Pasamos el NUEVO array filtrado a la función que dibuja la tabla
    UIModule.renderTable(filteredPets);
};

Concepto Clave

Los métodos funcionales de Arrays como .filter() o .map() no modifican el array original (son inmutables), sino que devuelven uno nuevo. Esto evita errores de pérdida de datos.

3. Objetos Literales y Desestructuración

ValidationModule.validatePetData() - app.js 
/**
 * Valida que los datos ingresados en el formulario sean correctos.
 * @param {Object} data - Objeto literal con toda la información del formulario.
 */
const validatePetData = (data) => {
    // DESESTRUCTURACIÓN DE OBJETOS (Object Destructuring)
    // Extraemos las propiedades del objeto 'data' y las convertimos en variables locales
    // Es equivalente a: const nombre = data.nombre; const tipo = data.tipo; ...
    const { nombre, tipo, edad, peso, dueno, telefono } = data;
    
    // Verificamos si alguna cadena de texto está vacía
    // En JS un string vacío "" es evaluado como un valor "Falsy"
    if (!nombre || !tipo || !dueno || !telefono) {
        showToast('Faltan campos obligatorios.', 'error');
        return false; // Detenemos la ejecución
    }
    
    // Si todo está bien, retornamos true
    return true; 
};

Concepto Clave

Agrupar datos en un Objeto Literal ({}) facilita pasarlos a funciones. La desestructuración nos permite extraer múltiples propiedades en una sola línea, mejorando la legibilidad.

4. Eventos del DOM (Delegación)

AppController.setupEventListeners() - app.js 
/**
 * Configuramos los eventos de clics usando "Delegación de Eventos"
 */
// Asignamos UN SOLO evento 'click' al contenedor padre (el cuerpo de la tabla )
tbody.addEventListener('click', (evento) => {
    
    // event.target es el elemento exacto que recibió el clic (podría ser el ícono )
    // .closest() busca hacia arriba en el DOM hasta encontrar la clase '.btn-delete'
    const btnDelete = evento.target.closest('.btn-delete');
    
    // Si el clic provino efectivamente del botón de eliminar...
    if (btnDelete) {
        // Obtenemos el ID de la mascota desde el atributo data-id HTML5 (ej: data-id="1612")
        const id = parseInt(btnDelete.dataset.id);
        
        // window.confirm() lanza una ventana nativa del navegador con Aceptar/Cancelar
        if (confirm('¿Estás seguro de eliminar este registro?')) {
            StateModule.deletePet(id); // Borramos de la memoria
            refreshUI();               // Refrescamos la pantalla
        }
    }
});

Concepto Clave

La Delegación de Eventos mejora el rendimiento drásticamente. En vez de crear un "listener" por cada botón de cada fila, escuchamos los clics en la tabla y detectamos qué botón fue pulsado.

5. API localStorage y JSON

StateModule.savePets() - app.js 
/**
 * Guarda el array actual de mascotas en el disco duro del navegador (localStorage)
 */
const savePets = () => {
    // REGLA: localStorage SOLO puede almacenar cadenas de texto (Strings).
    // NO puede almacenar Arrays ni Objetos complejos directamente.
    
    // 1. Usamos el objeto global JSON para "serializar" nuestro array
    // Esto convierte la estructura de JS a un bloque de texto formateado
    const dataString = JSON.stringify(pets);
    
    // 2. Guardamos ese texto en el navegador bajo la llave 'petcare_data'
    localStorage.setItem('petcare_data', dataString);
};

// NOTA PARA LEER: 
// Cuando queramos recuperar los datos, usamos localStorage.getItem()
// y luego JSON.parse() para volver a convertir el texto en un Array utilizable.

Concepto Clave

localStorage nos da persistencia para no perder datos al recargar. Como solo acepta texto, JSON (JavaScript Object Notation) es el puente para traducir nuestras estructuras de datos.

6. Flujo CRUD (Create, Read, Update, Delete)

Resumen de Arquitectura CRUD - app.js 
/**
 * El CRUD es el acrónimo para las 4 operaciones básicas de gestión de datos.
 * En nuestro patrón, todo modifica un Array (pets) y se guarda.
 */

// 1. CREATE (Crear): Instanciar un objeto nuevo e insertarlo
const createPet = (petData) => {
    pets.push(petData);  // Agregamos al final del Array
    savePets();          // Guardamos en LocalStorage
};

// 2. READ (Leer): Extraer los datos y dibujarlos en pantalla
const readPets = () => {
    return pets; // Luego otra función iterará esto para crear los  HTML
};

// 3. UPDATE (Actualizar): Buscar el modificado y reemplazarlo
const updatePet = (updatedPet) => {
    // Mapeamos el array. Si el ID coincide, retornamos el objeto modificado, si no, el original
    pets = pets.map(p => p.id === updatedPet.id ? updatedPet : p);
    savePets();
};

// 4. DELETE (Eliminar): Filtrar el array quitando el seleccionado
const deletePet = (idToDelete) => {
    // El nuevo array contendrá todas las mascotas MENOS la que tenga el idToDelete
    pets = pets.filter(p => p.id !== idToDelete);
    savePets();
};

Concepto Clave

El CRUD es el corazón de cualquier aplicación (Facebook, Twitter, tu app de banco). Modificar datos en memoria, persistirlos y luego renderizar la vista es el flujo de trabajo moderno en JavaScript.
